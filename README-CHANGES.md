## Run locally
1. Install Node.js (LTS).
2. Open a terminal in the `littlefinger` folder.
3. Run `npm install`.
4. Run `npm run dev`.

This ZIP intentionally excludes `node_modules`; npm will install the correct dependencies for your computer or Replit environment.
